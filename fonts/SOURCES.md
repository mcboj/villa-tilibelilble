# Local font sources

Cormorant Garamond (normal and italic, weight 300–700) and Manrope (normal, weight 200–800), variable WOFF2 from the official Google Fonts CSS API and fonts.gstatic.com. Retrieved 2026-10-15.

- https://github.com/google/fonts/tree/main/ofl/cormorantgaramond
- https://github.com/google/fonts/tree/main/ofl/manrope

The `latin` subset includes French accents, œ/Œ, euro and common punctuation. The `latin-ext` subsets are provided for additional European glyphs. Use the unicode ranges in /tmp/villa-assets.json when declaring separate subset font faces.

Both typefaces are distributed under the SIL Open Font License 1.1; their original OFL files are included in this directory. No requests to Google Fonts are needed at runtime.
